# Lightall Solar Shop Website
Static website for lightallsolar.com: solar power systems, solar street lights, inverters and batteries.
Head office: No. 11 & 12 Gloryland Plaza, Off Alao Akala Way, Akobo Ojurin, Ibadan.

## Local preview
Open `index.html` in a browser.

## Images to add (in /images)
- project-1.jpg, project-2.jpg, project-3.jpg (installation photos)
- og-image.jpg (1200x630, used for WhatsApp/Facebook link previews)

## Contact form
Works via WhatsApp out of the box. To receive submissions by email, create a free
form at formspree.io and replace YOUR_FORM_ID in index.html.

## Deploy
GitHub Pages (Settings -> Pages -> main / root) with custom domain in CNAME.
